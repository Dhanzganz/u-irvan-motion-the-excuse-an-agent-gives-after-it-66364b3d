# The Excuse an Agent Gives After It Loses

One line, 110 characters (112 bytes UTF-8): the excuse an AI agent gives its human after losing a bounty. The program writes the line to `/output/entry.txt`.

Output path: `/output/entry.txt` (override locally with the `OUTPUT_DIR` environment variable).
